# Project_pet - ระบบจัดเก็บและบริหารข้อมูลการฉีดวัคซีนสำหรับสัตว์เลี้ยง

## วัตถุประสงค์
- เพื่อพัฒนาระบบจัดเก็บและบริหารข้อมูลการฉีดวัคซีนสำหรับสัตว์เลี้ยงอย่างเป็นระบบ
- เพื่อประเมินประสิทธิภาพของระบบในการจัดการข้อมูลการฉีดวัคซีน
- เพื่อประเมินความพึงพอใจของผู้ใช้งานระบบ

## ขอบเขตของโครงการ

### 1. ความสามารถของระบบ (System Specification)

#### ฟังก์ชันของผู้ดูแลระบบ (Admin)
- จัดการข้อมูล Username / Password ของเจ้าหน้าที่
- เพิ่ม, ลบ, แก้ไขข้อมูล เจ้าหน้าที่, เจ้าของสัตว์เลี้ยง, สัตว์เลี้ยง, วัคซีน, และ อาสาสมัครประจำหมู่บ้าน
- เรียกดูข้อมูลวัคซีนที่หมดอายุ และตรวจสอบวัคซีนที่เกินกำหนดการฉีดผ่านระบบไลน์
- ออกรายงานสรุปข้อมูลประจำปี

#### ฟังก์ชันของเจ้าหน้าที่
- จัดการข้อมูล เจ้าของสัตว์เลี้ยง, สัตว์เลี้ยง, วัคซีน, และ อาสาสมัครประจำหมู่บ้าน
- ตรวจสอบข้อมูลวัคซีน, ออกรายงานประจำปี และแจ้งเตือนผ่านไลน์เช่นเดียวกับผู้ดูแลระบบ

#### ฟังก์ชันของประชาชน (ผู้ใช้ทั่วไป)
- ค้นหาข้อมูลประวัติการฉีดวัคซีนของสัตว์เลี้ยง
- ดูรายละเอียดสถิติและบุคลากรที่เกี่ยวข้อง

### 2. กลุ่มเป้าหมาย
- เจ้าหน้าที่ประจำหน่วยงาน
- อาสาสมัครประจำหมู่บ้าน
- ผู้ใช้ทั่วไปที่ต้องการตรวจสอบประวัติการฉีดวัคซีนของสัตว์เลี้ยง

## โครงสร้างระบบ

โปรเจค Project_pet มีโครงสร้างไฟล์ดังนี้:

### ไฟล์หลัก
- `index.php` - หน้าแรกของระบบ
- `login_official.php` - หน้าเข้าสู่ระบบสำหรับเจ้าหน้าที่
- `config.php` - ไฟล์การเชื่อมต่อกับฐานข้อมูล
- `search.php` - ระบบค้นหาสัตว์เลี้ยง
- `Check_pet.php` - ตรวจสอบข้อมูลสัตว์เลี้ยง
- `maps.php` - แสดงแผนที่พิกัดข้อมูลสัตว์เลี้ยง
- `statistics.php` - แสดงข้อมูลสถิติต่างๆ
- `Personnel.php` - ข้อมูลบุคลากร

### โฟลเดอร์
- `assets/` - รูปภาพและทรัพยากรต่างๆ
- `css/` - ไฟล์ CSS สำหรับการตกแต่งเว็บไซต์
- `js/` - ไฟล์ JavaScript สำหรับฟังก์ชันต่างๆ
- `include/` - ส่วนประกอบเว็บไซต์เช่น navbar และ footer
- `Database/` - ไฟล์ SQL สำหรับสร้างและอัปเดตฐานข้อมูล
- `people/` - ส่วนการจัดการข้อมูลเจ้าหน้าที่และผู้ใช้
- `profile/` - รูปโปรไฟล์ของผู้ใช้งานระบบ

## โครงสร้างฐานข้อมูล

ระบบใช้ฐานข้อมูล MySQL มีตารางหลักดังนี้:

1. **official** - ข้อมูลเจ้าหน้าที่
   - ID_OFF - รหัสเจ้าหน้าที่
   - User - ชื่อผู้ใช้
   - Pass - รหัสผ่าน
   - OFF_name - ชื่อเจ้าหน้าที่
   - num - หมายเลขโทรศัพท์
   - email - อีเมล
   - pst - ตำแหน่ง
   - user_role - บทบาทผู้ใช้ (admin/user)

2. **pet_own** - ข้อมูลเจ้าของสัตว์เลี้ยง
   - ID_PO - รหัสเจ้าของ
   - Po_name - ชื่อเจ้าของ
   - Hno - บ้านเลขที่
   - Moo - หมู่
   - ID - เลขประจำตัวประชาชน
   - Tel - หมายเลขโทรศัพท์
   - Po_email - อีเมล

3. **pet** - ข้อมูลสัตว์เลี้ยง
   - ID_P - รหัสสัตว์เลี้ยง
   - Type_pet - ประเภทสัตว์เลี้ยง (1: สุนัข, 2: แมว)
   - Breed - สายพันธุ์
   - Pet_name - ชื่อสัตว์เลี้ยง
   - Gender - เพศ
   - color - สี
   - weight - น้ำหนัก
   - p_old - อายุ
   - ID_PO - รหัสเจ้าของ (เชื่อมโยงกับตาราง pet_own)
   - status - สถานะ

4. **vaccine** - ข้อมูลวัคซีน
   - ID_VC - รหัสวัคซีน
   - V_name - ชื่อวัคซีน
   - V_storage - วิธีการจัดเก็บ
   - Expiration_date - วันหมดอายุ
   - Dosage - ขนาดวัคซีน

5. **history_v** - ประวัติการฉีดวัคซีน
   - ID_HV - รหัสประวัติ
   - HV_date - วันที่ฉีด
   - next_Hv_date - วันนัดครั้งถัดไป
   - ID_VC - รหัสวัคซีน (เชื่อมโยงกับตาราง vaccine)
   - ID_OFF - รหัสเจ้าหน้าที่ (เชื่อมโยงกับตาราง official)
   - ID_P - รหัสสัตว์เลี้ยง (เชื่อมโยงกับตาราง pet)

## คุณสมบัติของระบบ

### การแสดงข้อมูล
- แสดงข้อมูลสถิติในรูปแบบกราฟ (Chart.js)
- แสดงข้อมูลในรูปแบบตาราง (DataTables)
- แสดงแผนที่ตำแหน่งที่อยู่ (OpenStreetMap)

### การจัดการข้อมูล
- บันทึก แก้ไข ลบ ข้อมูลเจ้าหน้าที่
- บันทึก แก้ไข ลบ ข้อมูลเจ้าของสัตว์เลี้ยง
- บันทึก แก้ไข ลบ ข้อมูลสัตว์เลี้ยง
- บันทึก แก้ไข ลบ ข้อมูลวัคซีน
- บันทึก แก้ไข ลบ ประวัติการฉีดวัคซีน

### การรายงาน
- รายงานสถิติการฉีดวัคซีน
- รายงานสัตว์เลี้ยงที่ได้รับวัคซีน
- รายงานสัตว์เลี้ยงที่ยังไม่ได้รับวัคซีน
- รายงานวัคซีนที่ใกล้หมดอายุ

## การติดตั้งและใช้งาน

1. ติดตั้ง XAMPP หรือ web server อื่นที่รองรับ PHP และ MySQL
2. นำโปรเจคไปวางในโฟลเดอร์ `htdocs`
3. นำเข้าฐานข้อมูลจากไฟล์ SQL ในโฟลเดอร์ `Database`
4. เปิดเว็บเบราว์เซอร์และเข้าถึงระบบผ่าน URL `http://localhost/Project_pet`
