# Project_pet

วัตถุประสงค์
เพื่อพัฒนาระบบจัดเก็บและบริหารข้อมูลการฉีดวัคซีนสำหรับสัตว์เลี้ยงอย่างเป็นระบบ
เพื่อประเมินประสิทธิภาพของระบบในการจัดการข้อมูลการฉีดวัคซีน
เพื่อประเมินความพึงพอใจของผู้ใช้งานระบบ
ขอบเขตของโครงการ
1. ความสามารถของระบบ (System Specification)
ฟังก์ชันของผู้ดูแลระบบ (Admin)
จัดการข้อมูล Username / Password ของเจ้าหน้าที่
เพิ่ม, ลบ, แก้ไขข้อมูล เจ้าหน้าที่, เจ้าของสัตว์เลี้ยง, สัตว์เลี้ยง, วัคซีน, และ อาสาสมัครประจำหมู่บ้าน
เรียกดูข้อมูลวัคซีนที่หมดอายุ และตรวจสอบวัคซีนที่เกินกำหนดการฉีดผ่านระบบไลน์
ออกรายงานสรุปข้อมูลประจำปี
ฟังก์ชันของเจ้าหน้าที่
จัดการข้อมูล เจ้าของสัตว์เลี้ยง, สัตว์เลี้ยง, วัคซีน, และ อาสาสมัครประจำหมู่บ้าน
ตรวจสอบข้อมูลวัคซีน, ออกรายงานประจำปี และแจ้งเตือนผ่านไลน์เช่นเดียวกับผู้ดูแลระบบ
ฟังก์ชันของประชาชน (ผู้ใช้ทั่วไป)
ค้นหาข้อมูลประวัติการฉีดวัคซีนของสัตว์เลี้ยง
ดูรายละเอียดสถิติและบุคลากรที่เกี่ยวข้อง
2. กลุ่มเป้าหมาย
เจ้าหน้าที่ประจำหน่วยงาน
อาสาสมัครประจำหมู่บ้าน
ผู้ใช้ทั่วไปที่ต้องการตรวจสอบประวัติการฉีดวัคซีนของสัตว์เลี้ยง
